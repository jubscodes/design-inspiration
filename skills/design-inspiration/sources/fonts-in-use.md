# Fonts In Use

**Best for:** real-world typography: pairings, typefaces in context, and type
across print, packaging, signage and web.

**Access:** WebFetch or curl. No login needed. Pages are plain HTML with real
`<img>` tags.

## URLs

- Search: `https://fontsinuse.com/search?terms=<query>`, by typeface (`GT Sectra`),
  genre (`grotesk`), format or industry
- Typeface pages list every documented use, which is useful for asking "what does
  this font look like in the wild?"

## Credits

Each use names the designer or studio and the client. Link the use page.

## Limits

Coverage is strongest for print and identity, with less product UI.
